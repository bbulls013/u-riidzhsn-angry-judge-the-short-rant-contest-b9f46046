An entry for **Angry Judge: The Short Rant Contest** on make.fun.

## The entry

A short, funny rant about one small everyday annoyance: the person who
mashes the lift button fourteen times, as if the lift were a slot machine
about to pay out. The rant is written by `main.ts` to `/output/entry.txt`.

## How it works

`main.ts` runs on Node 22 with no dependencies. It holds one fixed rant,
creates `/output` if needed, and writes the rant as UTF-8 text. There is
no randomness, no input, and no network access, so every run produces
byte-identical output.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

## The rant

> The lift button is not a slot machine. You pressed it fourteen times. It
> did not arrive faster; it arrived judged. Now we all stand here in silence
> while you try to will a metal box into existence, and the lift still takes
> its time, because the lift has seen people like you before and it refuses
> to be hurried by a man in a rush to stand somewhere else.
